## 三、建议提交的截图

建议准备 8–10 张连续、清晰、带软件名称或页面标题的截图：

1. 首页：平台入口和元素周期表；
2. 数据库：搜索框、元素筛选、分页和材料表；
3. 材料详情：化学式、MP-ID、结构查看器；
4. Crystal Toolkit：晶胞、结构显示模式和交互控件；
5. Mechanical：弹性常数矩阵、体积模量、剪切模量和 ξ；
6. Phonon：声子能带与 DOS；
7. Thermal expansion：αxx、αyy、αzz、αV 曲线；
8. Predict：结构上传、QHA/AGV2 路由和任务状态；
9. ZTE：候选筛选、配比和混合曲线；
10. Agent：白名单工具查询或审批状态。

截图应去除浏览器收藏夹、个人路径、服务器地址、令牌和测试数据；建议统一浏览器缩放和窗口尺寸，按 1–10 编号保存 PNG。

## 四、源代码提交包

登记源代码应从最终冻结提交生成压缩包，保留 src/te_platform、datasets、docs、tests、pyproject.toml、锁定文件和启动说明。不应放入 API key、密码、Cookie、私有 SSH 配置、个人电脑绝对路径、.venv、缓存、日志和运行时上传文件。

按登记要求截取连续源代码页时，建议从入口、数据库服务、数据模型、曲线接口、预测路由和前端交互各选取连续代码段，并同时保存完整源代码归档。
