# 热膨胀材料智能计算与设计一体化平台 V1.0 用户手册

## 简介

平台用于检索热膨胀材料、查看结构和力学性质、分析各向异性热膨胀曲线，并开展结构预测与零热膨胀复合设计。当前数据包括 3665 条各向异性 NTE 材料和 185 条 PTE 参考材料。

## 数据库

使用化学式或 MP-ID 搜索，或点击元素周期表筛选。结果支持排序、分页和跳转页码；当前页会写入 URL。点击 MP-ID 或化学式进入独立详情页。

## 详情与结构

详情页按 Properties 组织信息。Mechanical 显示弹性常数、体积模量、剪切模量、键合模量和 ξ；Phonon 在有数据时显示声子能带和 DOS；结构查看器支持晶胞、键线、球棍、空间填充和多面体模式。

## 热膨胀

αV 是体积热膨胀主曲线；αxx、αyy、αzz 是 Cartesian 分量，方向性曲线用于观察各向异性。各分量可独立隐藏或显示，单位以页面标注为准。

## 预测与 ZTE

上传 CIF/POSCAR 后可选择快速预筛或精准计算：立方材料走 QHA，非立方材料走完整弹性张量 + AGV2。ZTE 页面返回体积分数、质量分数、误差和覆盖率；结果是模型估算，需实验验证。

## Agent 与数据边界

Agent 只能调用平台注册工具，状态改变操作须审批。数据库是经过筛选和质量门控的研究数据集；缺失字段不是零值，预测结果不是实验测量。
